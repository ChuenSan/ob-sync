有没有一种可能：我们同时用着好几个 AI，最后最忙的却是自己？

网页 GPT 负责讨论方案，本地 Coding Agent 负责写代码，而你负责：

**复制需求、搬运报错、转述建议、挑选会话、盯着编译，再追问一句 “到底做完没有？”**

两个窗口来回切，几个模型轮流聊，最后自己成了 AI 之间的人肉消息队列。

所以，我做了 **TaskQuay**：

> **让理解你需求的网页 GPT 统筹全局，直接查看已授权的本地项目，指挥本地 Coding Agent 干活，再把结果、验收证据和 Token 回执带回对话。**

**开源地址：[GitHub - wrfgup/taskquay: Visible tasks. Accountable local execution. Minimal Coding Agent Harness on MCP for ChatGPT, Claude. · GitHub](https://github.com/wrfgup/taskquay)**
