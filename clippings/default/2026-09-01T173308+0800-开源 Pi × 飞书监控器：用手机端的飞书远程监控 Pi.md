这是一个在飞书上控制你的 pi 的项目，可以实现远程监控，指令下发以及切换工作区的功能，主要就是远程！详细功能大家可以用着看，这里不过多赘述了。  
直接在终端中安装，下面是命令行（已经通过 npm 发包了，直接安装即可）  
npm install -g pi-feishu-monitor  
pi-feishu-monitor # 首次启动进入交互式配置向导，这里配置飞书的信息和 pi 的工作区（可以去飞书开发者后台中创建机器人，权限这里要有发送消息和接收消息，可以类比龙虾 ![:lobster:](https://cdn.ldstatic.com/images/emoji/twitter/lobster.png?v=15 ":lobster:")）

在飞书中发送帮助，可以看见下面的内容，就是一个远程的控制功能吧，把开发中一些常用的都写了进去， 欢迎各位佬友使用并提 pr，好用的话给一个免费的小 ![:glowing_star:](https://cdn.ldstatic.com/images/emoji/twitter/glowing_star.png?v=15 ":glowing_star:")！谢谢各位佬友。
