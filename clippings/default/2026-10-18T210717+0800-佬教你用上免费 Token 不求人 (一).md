七、掏心窝建议（干货）  
═══════════════════════════════

1. 别想着白嫖干一切。免费层有配额，要么按 RPM 限要么按 RPD 限，别拿来跑批量任务。
2. 多源切换。注册 Google + Groq + Mistral + Cohere 四个号，国内再开 DeepSeek + 智谱 + 硅基流动，凑齐 7 个免费源，日常用够了。
3. 配 OpenRouter 做兜底。$10 充一次解锁 1K RPM，免费模型随便调，重度用这个最稳。还有 clinepass 2 刀充值和 opencode (新上了 ds4. 1 和 glm5.3f 模型，不过得反代)，站里也有很多教程了，就不写了。反代的可以看看第三篇反代篇。
4. 自部署 gpt4free 是双刃剑。能跑但易封，别放生产环境，玩玩可以咯。
5. 国内环境首选硅基流动 + DeepSeek 官方，速度和稳定性都好，还不用绑卡。
6. 接 Cline / Cursor 用 OpenAI Compatible 模式，填 Base URL + Key 就行，不需要特殊配置。
7. 永久免费层只有 Google Gemini 和 Cloudflare Workers AI 两家真免费不绑卡，其他都是注册送 token 用完就要钱。
8. token 省着用的招：用 Cerebras/Groq 做快速迭代，用 Gemini 1M 做长上下文，用 OpenRouter 做兜底，按场景切换。
9. 别折腾破解版客户端、别用别人分享的 Key，封号比省钱快，这点我个人经验，也可以不认同。
10. 真要重度用，老实充钱，别又喷公益站模型不稳定又不充钱的，反正我被喷习惯了… 无所谓了。DeepSeek 官方 $0.27 / 百万 token，这可比免费折腾时间成本低多了。

复制即用，有补充评论区见。
