# 速览

## 一句话主旨

视频分享从算法方向转向 Agent 开发的学习与求职路径：补充大模型和 Agent 基础、阅读开源源码、自己 Vibe 一个 Agent、加入测试等改进，再准备后训练项目、刷题和面试，同时坦诚说明 Java、数据库与开发基础方面的不足。

## 核心要点

- 大模型基础可以通过 CS336 作业学习，Agent 基础则参考 `hello-agent`，视频建议快速阅读其中的第 1、2、3、4、8、9 章节。
- 阅读 Pi、nanobot、DeepSeek Harness 等开源项目源码时，可以让 AI 带着阅读，重点关注上下文管理、记忆系统等 Agent 核心能力。
- 在理解源码后，可以自己 Vibe 一个 Agent，再继续加入前端或测试框架等改进；视频作者在自己的 Agent 上集成了测试框架。
- 简历中还可以加入 Agent 后训练项目：可以复现论文内容，也可以包装开源项目并换一个业务场景重新训练；视频表示后者也得到过面试官认可。
- 完成上述学习和项目后，可以开始刷力扣并投递简历；视频称近期面试更关注项目，八股和力扣占比有所下降，并分享了一个月面试 18 场、手撕约 8 场的经历。
- 视频作者坦诚自己没有系统学习 Java、不会数据库，过去实习偏算法，开发能力和开发八股基础较弱；如果暂时找不到合适机会，可以先去小厂积累实习经验。
