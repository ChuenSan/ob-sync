# 速览

## 一句话主旨

作者开源的 AI 视频剪辑 Skill 面向口播视频，通过语音转文字、停顿检测、上下文整合、AI 决策和 FFmpeg 执行五步流程，自动删除长时间停顿与重复语句；它不绑定特定剪辑软件，但对画面、音效丰富或无人声片段的处理仍有限制。

## 核心要点

- 这款 AI 视频剪辑 Skill 专为口播视频设计，能够自动识别并删除长时间停顿、口误和重复语句；作者称其剪辑准确率可达 90% 以上。
- 工具直接处理现成视频文件，不依赖特定剪辑软件，因此不受 Screen Studio 等软件绑定限制。
- 剪辑流程分为五步：使用百炼 ASR 转录音频，利用 Silero 模型检测空白片段，整合转录文本与时间轴等数据，由 Agent 判断剪辑点，最后调用 FFmpeg 执行剪辑。
- AI Agent 不直接处理视频帧，而是基于转录文本、逐字时间轴、停顿标记和剪辑规则等程序预处理数据做决策。
- Agent 的输出包括需要删除或保留的剪辑片段、决策自信度和删除原因，其中删除原因可用于后续迭代优化。
- 当前 Skill 最适合纯口播视频；包含丰富画面、音效或无人声片段的视频，可能需要进一步优化才能达到理想效果。
- 使用时可以在 Skill 平台搜索并安装 `video-editor` Skill。

# 视频原文

AI视频剪辑Skill：原理与使用指南

作者开源了一款AI视频剪辑Skill，专为口播视频设计。它能自动识别并删除长时间停顿和重复语句，将剪辑准确率提升至90%以上。该工具不依赖任何特定剪辑软件，可直接处理现成视频文件。

核心功能与优势

这款Skill主要解决口播视频中常见的剪辑痛点，让视频节奏更紧凑。

功能 说明
删除长停顿 自动识别并移除音频中的空白片段，让视频更流畅。
消除重复语句 通过语音识别，智能判断并剪掉口误或重复的内容。
高准确率 作者通过与手动剪辑对比测试，剪辑准确率可达90%以上。
通用无绑定 直接处理视频文件，不与任何剪辑软件（如Screen Studio）绑定。

工作原理：五步剪辑流程

该Skill通过一套完整的流程，结合程序处理与AI判断，实现精准剪辑。

语音转文字：使用百炼ASR模型将视频音频转录为文字和字幕。
识别停顿：利用Silero模型寻找音频中的空白位置。
数据整合：将转录文本、逐字时间轴、停顿标记等数据整合成上下文。
AI决策：Agent基于上下文和剪辑规则，判断具体的剪辑点。
执行剪辑：使用FFmpeg库对视频进行实际的剪辑处理。

AI Agent的决策过程

AI Agent是整个剪辑流程的“大脑”，它基于程序预处理的数据进行决策，而非直接处理视频帧。

输入数据 输出决策
转录文本
逐字时间轴
停顿标记
剪辑规则 剪辑片段 (删除/保留)
决策自信度
删除原因 (用于迭代优化)

局限性与适用场景

该Skill目前最适合处理纯口播类视频。如果视频包含丰富的画面、音效或无人声的片段，可能需要进一步优化才能达到理想效果。

如何使用

在Skill平台搜索并安装 video-editor Skill即可使用。
