# 速览

## 一句话主旨

视频介绍一套经过两个月打磨、免费开源的个人AI工作台，包含个人知识库可视化、热点信息、社媒讨论搜索和抖音数据呈现四个模块，并支持通过AI工具安装、授权和继续扩展。

## 核心要点

- 个人知识库可视化模块会对知识库文件进行分类，并以知识星图、Wiki层、素材层和书架等需求模块呈现。
- 热点模块通过AI热点API接口和策略筛选生成内容，用户拿到项目后可以根据自己的需求调整筛选策略和输出内容。
- 社媒讨论搜索模块支持围绕某个话题使用关键词检索不同社交媒体上的讨论，帮助了解不同观点、挖掘潜在需求和寻找选题方向。
- 抖音数据模块聚合创作者后台中分散在不同模块的数据，将原本分散的信息集中到一个页面统一呈现。
- 项目开源后，可以复制安装指令交给AI工具执行；启动后页面默认显示假数据，需要替换为用户自己的数据。
- 已有个人知识库的用户可以让AI工具对接并接入自己的知识库；没有知识库的用户可以先搭建个人知识库再接入工作台。
- 社媒和抖音数据模块依赖两个配套Skill，安装后需要按照页面说明完成登录授权，再让AI工具执行对应操作。
- 工作台可以继续扩展：既可以提取已有界面的UI设计Token，也可以让AI工具修改不合理或不满足需求的模块。
- GitHub 开源地址：https://github.com/oyorf/person_dashboard
