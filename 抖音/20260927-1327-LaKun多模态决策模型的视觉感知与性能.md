# 速览

## 一句话主旨

视频介绍了开源多模态决策模型 LaKun：它在 Jev 和 Laya 的决策范式基础上加入视觉感知能力，通过大规模自定义数据微调，实现图像或文本输入下的候选决策，并强调其 0.7B 级参数规模、毫秒级文本推理和特定场景应用价值。

## 核心要点

- LaKun 借鉴 Jev 的决策范式和 Laya 的优化思路，增加视觉输入能力，可接收图像或文本并对多个候选选项分配概率，输出得分最高的决策结果。
- 模型支持三种任务类型：Choice 用于多选决策，Score 用于选项打分排序，Rank 用于选项优劣排序。
- 作者构建了约 38 万条自定义微调数据集，数据由公开数据和文本数据共同构成，覆盖视觉与文本等领域，并使用约 3.8 万条数据作为测试集。
- 视频介绍模型测试准确率达到 90% 以上，表格列出的 Choice 和 Score 测试集准确率分别为 86.14% 和 85.21%。
- 纯文本推理延迟约为 18ms，带图片推理平均约为 160ms，体现了小参数模型在速度方面的优势。
- LaKun 在 Laya 架构上增加视觉编码器，将视觉特征与文本特征融合后送入联合编码器训练，总参数量约为 0.75B，CPU 运行所需内存大于 8G。
- 代码和模型权重已全部开源，可通过 `pip install lakun` 安装使用。
- 视频探讨了其在内容审核、企业图片审核以及发票和单据等财税票据处理场景中的应用价值。

# 视频原文

这个视频介绍了一款名为 LaKun 的开源多模态决策模型。该模型在借鉴 Jev 和 Laya 等前人工作的基础上，为其决策范式增加了视觉感知能力。视频详细讲解了 LaKun 的开发动机、在38万条自定义数据上的微调细节、90%+的测试准确率，以及0.7B参数规模下18ms级别的推理速度。最后，还探讨了这类模型在内容审核、票据处理等特定场景下的应用价值。
模型特点与决策范式
LaKun 模型的核心特点是将视觉感知与决策能力相结合。它借鉴了 Jev 的决策范式和 Laya 的优化思路，并增加了视觉输入能力。模型接收图像或文本作为输入，并能对多个候选选项进行概率分配，最终输出得分最高的决策结果。
- 视觉决策：模型能实时分析图像，并基于视觉信息做出判断。例如，在“跑酷小游戏”场景中，它能根据当前画面决定角色下一步是“跳”还是“蹲”。
- 统一输出：输出与 Jev 保持一致，支持三种任务类型：
- Choice：在多个选项中做出选择。
- Score：对选项进行打分排序。
- Rank：对选项进行优劣排序。
数据集与性能指标
为了提升模型的泛化能力，作者构建了一个包含38万条数据的自定义微调数据集，远超 Laya 本身的 6000 条数据。该数据集由公开数据和文本数据共同构成，覆盖了视觉和文本等多个领域。在包含 38,000 条数据的测试集上，模型取得了优异的性能。

模型架构与部署
- 架构设计：模型在 Laya 架构基础上，增加了一个视觉编码器。视觉特征与文本特征融合后，再送入联合编码器进行训练。
- 参数量：总参数量约 0.75B。
- 部署要求：CPU 端运行只需大于 8G 的内存。
- 开源情况：代码和权重已全部开源，可直接通过 pip install lakun 安装使用。
应用场景探讨
视频认为，通用大模型与专用小模型将长期并存。LaKun 这类小模型因其速度快、效果好，在以下场景中具有天然优势：
- 内容平台：用于识别和拦截仅通过图片发布的引流、违规内容。
- 企业审核：快速判断图片中是否存在特定信息，替代传统 OCR 或效果不佳的小型 VLM。
- 财税票据：审核发票、单据等，确认关键信息是否齐全。
