# 速览

## 一句话主旨

Data Agent是用大模型编排数据并完成数据配置、清洗、集成、探索和分析等任务的系统，论文以L0到L5划分其自主程度，帮助判断产品从交互式辅助到高度自主的能力边界，以及从L2迈向L3时面临的任务规划、数据质量、环境变化和安全责任难题。

## 核心要点

- “智能分析”“AI分析师”“AI数据科学家”等宣传词可能指向不同能力水平，视频介绍的论文以L0到L5建立了Data Agent的分级标准，用于区分产品的实际自主程度。
- Data Agent的核心链路是：在环境中处理原始数据，使用模型面向具体任务，最终产出结果；只有这条链路完整，才被称为Data Agent。其与通用Agent的主要区别在于，Data Agent可以自主串联数据分析中的重要模块，人只在关键节点进行审核检查。
- L0是人工完成数据获取、清洗、分析、找方向和给出结论；L1是人与AI交互，由AI根据表名和字段名写查询语句，再由人执行查询、查看数据并让AI辅助分析。
- L2可以连接知识库和数据库，自主执行查询、查看报错、修改查询语句并完成分析，但整条链路的先后顺序和执行方式仍由人决定；L3则能根据目标自主拆解任务、判断数据可信度、决定是否清洗或补充数据，人主要负责审批和验收。
- 从L2走向L3的难点包括：模型难以为复杂多变的真实任务安排正确顺序；前置数据错误可能在后续分析阶段才暴露；表结构、字段和业务口径会持续变化；AI结论涉及真实企业决策，必须设置人工安全护栏并明确责任。
- L4代表高度自主的数据管家，能够持续监测数据问题、结论漂移和分析价值并主动处理；L5代表完全自主，不仅使用现有工具，还能提出新方法、迭代升级、设计实验并反哺数据库。
- 视频认为目前大多数产品仍处于L1，少数团队能做到L2，L3仍属于前沿探索，许多产品大约处在L2.5；视频还提到论文团队开源了一个L3水平的Data Agent及可本地部署的小模型。
