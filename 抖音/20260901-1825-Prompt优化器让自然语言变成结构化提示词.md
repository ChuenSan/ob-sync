# 速览

## 一句话主旨

视频介绍开源项目 Prompt Optimizer：用户先用自然语言说明需求，工具再将其拆解为角色、任务、目标、限制条件和输出格式，并支持持续迭代优化及前后回答的分析对比，覆盖系统提示词、用户提示词和多种生成场景。

## 核心要点

- 直接向 AI 输入“帮我写一个产品方案”这类过于随意的提示词，虽然能够得到回答，但视频认为最终结果大概率比较普通。
- Prompt Optimizer 会把原本随意的一句话重新拆解为角色、任务、目标、限制条件和输出格式，再生成结构更完整的提示词。
- 这个项目不只是对提示词进行润色，还支持继续迭代优化，并将优化前后的回答放在一起分析、评估和对比。
- 工具可以处理系统提示词和用户提示词，视频还提到它考虑了文生图、图生图和多轮对话等使用场景。
- 视频认为，使用 AI 时不一定要先学会编写很长、很复杂的提示词，用户可以先把想做的事情说明白，再由工具继续完善提示词结构。
- 视频最后表示，这类工具降低了不会写提示词的使用门槛，但具体项目效果仍以原文描述为准。
