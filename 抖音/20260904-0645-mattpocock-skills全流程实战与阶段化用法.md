# 速览

## 一句话主旨

视频通过一个秒杀系统的完整案例，演示 mattpocock-skills 从项目初始化、需求澄清、PRD生成、原型设计，到编码、Review、Bug调试、Agent交接和交互式学习的使用阶段，并强调简单、自由和按需组合技能的设计理念。

## 核心要点

- mattpocock-skills 是一组面向工程师的AI编程技能，视频称其在GitHub上获得了接近150K个Star；它强调保持用户控制权，而不是像部分复杂工作流那样接管全部流程。
- 安装后应先执行项目初始化技能，确定任务追踪方式、标签词汇表、单一或多上下文结构，以及创建 `CLAUDE.md` 或 `AGENTS.md` 等项目约束文件。
- 需求模糊时，先使用偏采访和澄清的技能深入讨论；如果需要将讨论结果、定义和决策落成文档，则使用会生成文档的需求沟通技能。
- 需求明确后，小任务可以用Issue类技能保存，大需求可以用PRD技能生成文档，内容包括用户故事、实现决策、范围边界、技术栈、数据库设计和API路由等。
- 页面没有明确设计方向时，可以使用原型设计技能生成多个可交互方案，选择其中一个后再转换为正式页面，适合登录注册等需要先确认视觉方案的场景。
- AI生成较多代码后，可以使用代码Review技能扫描代码库，输出可优化的问题和说明文档，为后续迭代增加检查环节；遇到顽固Bug时，可以使用多种测试方向进行排查和调试。
- 切换Agent或中断当前会话时，使用Handoff技能生成交接文档，让新的Agent读取当前约定、进度和后续工作，避免重新解释背景。
- Teach技能适合非开发任务或学习场景，会检索权威资料生成可交互课程，并结合测验、反馈和逐课推进学习工具或概念。
- 这些技能可以按阶段自由组合：先澄清问题，再沉淀需求，随后设计、开发、Review、调试和交接，不要求每次都执行完整流程。
