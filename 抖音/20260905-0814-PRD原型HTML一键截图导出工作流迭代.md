# 速览

## 一句话主旨

针对HTML格式原型不便复制到公司文档的问题，作者放弃直接将原型生成图片的方案，保留HTML以便继续修改，并增加在当前页面一键导出截图的功能，期间通过更换实现思路、调整保存路径和文件位置解决导出问题。

## 核心要点

- HTML原型不是图片，复制到公司文档时可能只能复制文本，原型图区域会变成空白，因此不便直接复用。
- 将原型直接改成图片虽然方便复制，但会增加后续微调的复杂度；为了兼顾可修改性，最终保留HTML格式，增加一键导出截图功能。
- 截图导出功能的实现曾出现字体、图形和图标整体向下偏移的问题，作者尝试多种方案和模型，经过约一小时仍未解决，说明原方案可能存在问题。
- 后续改用在当前页面通过类似插件的方式计算位置并截图，而不是单纯在代码层面生成截图；同时调整图片保存路径，避免每次都保存到原始路径。
- 一键截图功能应放在原型文件的HTML中，而不是原有的PRD需求文档HTML中；删除“一键导出所有截图”的提示后，系统会自动完成截图。
- 最终版本仍存在图标位置等小瑕疵，但已经达到可用状态，可以直接复制截图，减少手动截图和粘贴的操作。
- 当一条实现路径长期无法解决问题时，可以及时更换思路，而不是持续在同一方案上反复修改。
