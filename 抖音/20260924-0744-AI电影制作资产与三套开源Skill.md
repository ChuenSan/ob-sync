# 速览

## 一句话主旨

视频介绍一部据称耗资 50 万美金、时长 95 分钟的 AI 电影及其公开的 11 万份制作资产，并重点展示已在 GitHub 开源的 Higgsfield Skills 如何分别处理图像提示词、视频提示词和人物表演，将导演、摄影与表演经验封装为可复用的创作能力。

## 核心要点

- 视频称，一部耗资 50 万美金、制作时长较长的 95 分钟 AI 电影上线后，主创团队公开了 11 万份制作资产，分享内容不只包括零散提示词，而是覆盖整部电影的制作资料。
- 这些公开资产被描述为电影团队完成长片制作后沉淀的实践经验，能够让学习者参考角色、场景、镜头和连续性等具体制作问题的解决方式。
- 已在 GitHub 开源的 Higgsfield Skills 包含三套 Skill，分别面向图像提示词、视频提示词和人物表演：第一套处理角色、场景与视觉资产，第二套控制镜头动作和多镜头连续性，第三套强化人物的表演表现。
- 视频通过同一人物、同一句台词和同一个 2.5 模型进行对比，声称直接生成的结果像是在念稿，而经过人物表演 Skill 处理后，眼神、停顿、呼吸、手势、身体动作和微表情更具层次。
- 人物表演 Skill 会将简单的情绪描述继续拆解为眼神变化时机、身体前倾节点、说话前停顿时长、手部动作和情绪爆发节点，从而把“让人物动起来”推进到“让人物表演”。
- 视频认为，AI 视频创作的差距可能不只取决于模型选择，还取决于能否将导演、摄影和表演等专业能力封装为可反复调用的 Skill。
- 视频表示，95 分钟 AI 电影的完整创作文档和三套核心 Skill 的 MD 文件已经整理为文档，供用户进一步参考使用。
