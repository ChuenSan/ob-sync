# 速览

## 一句话主旨
视频介绍了驱动Codex的一套Harness架构及其相关组件开源，强调开源内容不是模型本身，而是负责上下文、工具和审批边界的运行框架，包括SDK与APP server；这套双向协议终端理论上可以被改造成新的智能编码终端。

## 核心要点

- 视频所说的开源对象是Harness架构，而不是开源模型；项目采用Apache 2.0许可证，允许修改、商用和继续分享代码。
- 开源的核心组件包括相关官方SDK和APP server，其中APP server被认为是最有价值的部分，因为VS Code插件、网页端等界面都可以运行在这套双向协议终端之上。
- Harness负责重新定义模型之外的工作机制，包括上下文组织、工具调用、审批边界和任务执行规则，因此能够决定Agent如何拆解任务并推进工作。
- 用户理论上可以基于这套Harness打造自己的智能终端，只需重新设计终端能力和交互方式，而底层仍复用同一套Agent运行架构。
- 视频认为模型能力未来可能逐渐趋同，开发者竞争的重点会转向谁能设计出更好的Harness和智能体工作系统。
