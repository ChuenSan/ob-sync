# 速览

## 一句话主旨

视频演示将视频剪辑工具与Agent结合，自动安装插件、完成口播粗剪、添加素材和视觉风格、套用模板，并在只有一个想法时调用图片与视频模型生成素材后自动合成短片。

## 核心要点

- 通过Agent发送指令后，系统会自动安装剪辑插件，并打开类似传统剪辑软件的界面；视频称其效果由前端代码实现，因此更适合由AI完成剪辑。
- 将口播素材和脚本交给AI后，可以自动完成初剪，视频作者称原本至少需要一小时的工作可以更快完成。
- AI生成的画面不一定第一次就符合个人审美，可以选择预设视觉风格后重新生成，以获得更符合预期的效果。
- 可以先用生图模型生成关键帧示意图，再让剪辑工具还原画面效果；视频还提到搭配新模型可生成更有惊喜的动画效果。
- 视频工具支持直接套用模板，模板包含动画、音效、转场和特效等内容，可以拖拽到轨道后再让AI修改为自己的内容。
- 即使没有现成素材、只有一个创意，也可以让AI先分析内容，再调用图片模型和视频模型生成素材，最后自动剪辑、合成产品广告。

# 视频原文

你现在看到的特效、字幕、音效全都是ai帮我加上的。只需要chatcut加上agent，就可以简口播、做动画、做短片，并且过程都非常的简单，让我一分钟教会你。我是黄白，一个很会玩ai的设计师。
- 首先来到agent，接着发送这段指令，这个agent会自动安装checkcut的插件，然后它会打开一个和传统剪辑非常类似的界面，但它的效果是由前端代码来实现的，所以就天然的更适合ai去完成剪辑。
- 首先把一堆口播素材和脚本发给ai，可以看到ai正在自动的剪辑，很快的就剪好了。以往这个初剪阶段至少要花我一个小时，现在就一个字爽。
- 接着又要求来加上一些素材来丰富画面，说实话这个第一次生成的效果不是很符合我的审美。不过我发现这里是可以选择预设的视觉风格的，选中之后再生成的效果就很对味了。
- 还有一个技巧是可以先用生图模型生成这样的关键帧示意图，再让checkcut还原效果会更好。而且搭配新出的五点六so，还能有很惊喜的动画效果。我还做了一个黄黑色的风格school，可以开卷出来给大家使用。
- 除此之外我还发现这里可以直接套用模板，动画、音效、转场、特效全都有，可以直接拖拽到轨道上，再让ai修改成自己的内容就有很好的效果了。
- 最后如果没有素材，只有一个想法的话，也可以直接告诉chatcat，ai会先分析内容，用图片模型和视频模型生成之后，再进行剪辑、合成，就可以自动做出这样的产品广告了。全过程都是chatcat自动生成并剪辑的。
