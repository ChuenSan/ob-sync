# 速览

## 一句话主旨
视频介绍一款将大模型线性聊天转换为非线性对话地图的插件2.0版本，重点展示动态加载、追问与快捷提示词、侧边栏详情、工具调用记录、对话状态和深色模式等更新，并说明其主要服务于代码构建和学习场景。

## 核心要点

- 插件将传统线性对话转换为可展开、追问和分支的对话地图，帮助用户在长对话中定位上文问题和概念关系。
- 2.0版本针对大量卡片进行动态加载，只加载当前屏幕可见内容，以避免画布中存在几千或几万张卡片时拖动卡顿。
- 学习场景新增追问功能，用户可以针对不理解的概念继续提问，并使用展开说明等快捷提示词减少输入；快捷词也可以自行新增。
- 右侧侧边栏用于查看卡片详情，不仅能看文本，还能展示工具调用记录、ask user question等澄清卡片和每轮对话的工具调用数量。
- 插件增加每轮对话实现状态展示，用于说明余额不足或本轮出现故障等情况，减少用户在没有反馈时的无谓等待。
- UI方面优化了分支图标、详情归档、跳转到对话和定位等交互，并增加随DeepPC Harness变化的深色模式。
- 作者表示插件初衷是尽量贴合Deep Harness的原生功能，保持轻量化，而不是在原有对话系统之外堆叠大量新功能。
