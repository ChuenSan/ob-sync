# 速览

## 一句话主旨

视频以制作电子书阅读器为例，介绍使用 AI 编程时从环境搭建、产品设计、技术设计、产品实现到人工验证的五步流程，并强调版本管理、AI 自测和人工验证是尽量不能省略的三个环节。

## 核心要点

- 作者认为，直接给 AI 一条指令虽然可以生成软件，但最终交付结果可能与预期不一致，也可能存在较多 bug，因此需要通过流程提高结果的可控性。
- 环境搭建主要包括创建项目文件夹、初始化 Git 仓库，以及编写 agents.md 项目说明文件，让 AI 了解项目背景和开发约束。
- agents.md 中可以规定每次改动后创建 Git commit，并编写或更新测试，在交付前完成测试和验收。
- 产品设计阶段先明确 MVP 范围，围绕核心功能与 AI 讨论做什么、不做什么，并在必要时制作只包含前端和模拟数据的 DEMO。
- DEMO 适合后端实现成本较高、需要提前验证界面与交互的项目；后端逻辑简单的项目可以直接实现完整产品，减少重复劳动。
- 技术设计阶段需要根据产品设计文档讨论技术栈和架构，并形成技术方案文档，作为后续代码实现的参考依据。
- 产品实现阶段应让 AI 读取产品设计和技术方案，完成代码、自测和修复；可通过 computer use、Chrome 等插件提供验证环境。
- 作者总结的五步流程是环境搭建、产品设计、技术设计、产品实现和人工验证，并强调版本管理、AI 自测、人工验证三项原则应尽量坚持，设计环节的详细程度则根据需求复杂度和重要性取舍。
