# 速览

## 一句话主旨

作者演示安装并调用自己开发的 Oil Motion 动画 Skill，通过图片生成、视频生成和 AI agent，将角色扭头、鼠标跟随、滚动驱动的一镜到底等效果制作成官网交互，并展示真人素材一致性与镜头变化方面的限制。

## 核心要点

- 作者最初为官网制作小狗扭头动画，随后将 Skill 用于鼠标跟随、滚动驱动和产品展示等官网动画效果。
- 安装时可在 GitHub 搜索 Motion Skill，或从作者官网进入 Skill 模块找到仓库；复制仓库链接后交给任意 AI agent 安装。首次调用时需要按 Agent 提示配置 API。
- 视频中提到，其他 Agent 可能同时调用生图模型 GPT image 2 和生视频模型 MiniMax H3 Max，后者被作者描述为生成速度较快、性价比较高且效果不错。
- 使用者可以明确指定动画效果；如果尚未确定方向，也可以提供有限上下文，让 Skill 根据内置的动画最佳实践发散创意。
- 真人扭头案例只使用一张参考图，设置为鼠标左右移动控制角色实现 360° 扭头；生成图片、视频并转成雪碧图后，页面即可实现交互，但真人一致性不如卡通素材，部分角度可能产生恐怖谷效应。
- 滚动案例以雕塑从原材料到成品为主题，页面滚动依次呈现粗糙石头、雕琢打磨、特写镜头和展厅展示；作者认为如果加入不同镜头变化，效果会更惊艳，也可以将鼠标跟随和滚动变换结合起来。
