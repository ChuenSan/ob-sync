# 速览

## 一句话主旨

视频介绍使用MCP Inspector绕过大模型，直接对MCP Server进行交互式调试和工具测试，演示其安装、添加远程服务、查看工具、传入参数调用，以及配置身份认证后断开重连使配置生效的基本流程。

## 核心要点

- MCP Inspector用于在浏览器、命令行或终端中调试MCP服务，视频后续主要围绕交互式界面展开，直接测试MCP Server本身而不经过大模型。
- 视频提到MCP Inspector提供三种安装方式，并以其中的交互式界面演示后续操作。
- 添加MCP服务时，需要点击添加按钮、设置Server ID，并在本地服务与远程服务之间进行选择；视频以已经部署好的远程彩云天气MCP服务为例，通过URL添加服务。
- 服务连接成功后，可以查看该MCP服务提供的工具列表及工具说明。视频展示的彩云天气服务共有五个工具，其中包括获取指定位置实时天气和获取未来72小时小时级天气的工具。
- 调用天气工具时需要输入经纬度，视频演示通过高德地图的坐标拾取功能获取位置坐标；首次调用因缺少身份认证Key失败。
- 完成相关平台注册后，需要从应用管理的访问控制中复制Token，将其填入MCP服务设置中的Key参数，然后断开并重新连接服务，再次调用工具验证配置是否生效。
