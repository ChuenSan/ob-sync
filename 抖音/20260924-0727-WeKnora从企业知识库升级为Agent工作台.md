# 速览

## 一句话主旨

WeKnora v0.8.0 通过安全沙箱、技能系统、长期记忆和产物管理等升级，将能力从知识库问答扩展到问题解决与任务执行，并补充会话管理和多格式文件解析，定位为面向企业场景的 Agent 工作台。

## 核心要点

- WeKnora v0.8.0 的核心变化是从“回答问题”转向“解决问题”，产品定位也从企业知识库框架扩展为集成知识、记忆、技能和安全执行环境的 Agent 工作台。
- 安全沙箱支持为每个会话配置独立的 Docker、E2B 或 CubeSandBox 环境，使 Agent 能在隔离环境中运行脚本，并独立管理密钥、环境变量和出网策略。
- 技能系统支持从 cloudhub、GitHub 或本地压缩包安装技能，用户可以查看技能目录、安装过程和结果报告，并为 Agent 绑定沙箱、限制其可访问的技能范围。
- 长期记忆会自动提取用户画像、偏好、待办事项和长期关注点，用于支持后续对话衔接；产物管理则将 Agent 生成的 HTML、Office 文档、图片和代码以产物卡片集中展示。
- 产物卡片支持在线预览、集中查看和下载，使 Agent 生成的文件不再只停留在对话文本中，而是作为可管理的结果交付给用户。
- 会话管理新增会话大纲、创建时间和上下文压缩时间轴，帮助用户了解会话结构和上下文处理过程。
- 解析能力内置 Android 解析引擎，并新增对 GitLab、腾讯 iM、XMind 等文件格式的解析支持；视频认为这些能力适合内部知识库、智能客服和 RAG Agent 开发场景。

# 视频原文

WeKnora v0.8.0：从“问答”到“执行”的飞跃

WeKnora 0.8.0 版本迎来重大升级，核心能力从“回答问题”进化为“解决问题”。通过引入安全沙箱、技能系统和长期记忆，它已从一个企业知识库框架，转变为一个功能全面的 Agent 工作台。

核心升级：三大支柱

1. 安全沙箱 (Sandbox)
为每个会话配置独立的 Docker、E2B 或 CubeSandBox 环境。Agent 可在隔离环境中安全运行脚本，并独立管理密钥、环境变量和出网策略，有效保护内网和敏感数据。

2. 技能系统 (Skills)
支持从 cloudhub、GitHub 或本地压缩包安装技能。可查看技能目录、安装过程和结果报告。Agent 可绑定自己的沙箱，并限制其能访问的技能范围。

3. 长期记忆与产物管理
长期记忆：系统会自动提取用户画像、偏好、待办事项和长期关注点，供后续对话无缝衔接。产物管理：Agent 生成的 HTML、Office 文档、图片和代码会以产物卡片形式展示，支持在线预览、集中查看和下载。

其他增强功能

会话管理：新增会话大纲、创建时间和上下文压缩时间轴。
解析能力：内置 Android 解析引擎，新增对 GitLab、腾讯 iM、XMind 等文件格式的解析支持。

总结：从框架到工作台

WeKnora 0.8.0 已不再只是一个知识库，而是一个集成了知识、记忆、技能和安全执行环境的 Agent 工作台。对于内部知识库、智能客服或 RAG Agent 开发者而言，这次更新使其成为一个更强大、更实用的工具。
