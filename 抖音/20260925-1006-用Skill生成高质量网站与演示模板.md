# 速览

## 一句话主旨

视频展示作者用三个小时制作的 Skill 及其生成效果：通过内置十八套模板，将商业级网站的审美、排版和动效规则整理成 AI 能理解的语言，用普通自然语言提示生成网站、玩偶展示页面和 PPT。

## 核心要点

- 视频作者表示，自己制作的 Skill 已入围世界人工智能大会，并用它做出了星球、潮玩手办和电影主题等多种模板。
- 星球模板可以搭配生图工具生成太空卡通形象；潮玩手办模板支持展示泡泡玛特玩偶、左右切换玩偶和更换背景颜色。
- 电影主题模板被用于生成学习网站，另外两个 PPT 也由同一个 Skill 生成，其中 Skill 介绍 PPT 可以通过一句话直接生成。
- 生成这些作品时使用的提示词是日常化的大白话，复杂效果主要来自 Skill 内置的十八套模板和整理好的设计规则。
- Skill 将商业级网站的审美、排版和动效规则转成 AI 能理解的表达，作者计划继续更新更多模板。

# 视频原文

大家好，我花了三个小时制作的skill已经入围了世界人工智能大会。这个是我为了致敬大会的官网刚刚做好的星球模板，可以搭配生图工具把自己做成好看的太空卡通形象。这个潮玩手办的模板我用它做了泡泡玛特的玩偶展示，左右切换玩偶还可以更换背景颜色。这个是电影主题的模板，我也用它生成了一个学习的小网站，包括后面两个ppt都是我用这个skill生成的，其中这个skill介绍的ppt更是用一句话直接生成的。这些都是我一开始给i的提示词，都是纯纯的大白话。是因为我在这个skill中内置了十八套不同的模板，把很多商业级网站的审美、排版还有动效规则都整理成了ai能听懂的语言。后续我还会更新更多更高级、好看的模板，也希望大家可以在github上给我点个star支持，收藏下。
