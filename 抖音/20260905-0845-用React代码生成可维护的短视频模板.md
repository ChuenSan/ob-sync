# 速览

## 一句话主旨

视频介绍一个基于React的视频生成框架，通过帧号控制文字、卡片、颜色、转场和动画，再将各帧与音频编码为视频；它还能把成片封装为可复用、可参数化、可预览和可自动渲染的长期维护模板。

## 核心要点

- 视频中的标题、卡片、颜色、转场和元素出现的帧数都由React代码控制，成片可以直接证明这套方式的实际效果。
- 框架向React提供当前帧和空白画布，React根据帧号计算文字位置、透明度和动画状态，渲染器再把所有帧与音频编码成视频，因此视频不是网页录屏，而是随时间变化的React组件。
- 这种方式的核心价值是把一次性成片变成可维护的视频模板：片头、字幕、图表和品牌元素可以封装为组件，文字、图片、数字和颜色可以通过参数传入同一套模板。
- 视频归纳了四个特点：使用React组件和设计系统实现组件化；让数据决定内容甚至时长的参数化；用Player把可编辑视频嵌入React应用的产品化；通过CLI、Node.js、Lambda或Cloud Run接入生产流程的自动化。
- 最小使用流程包括创建项目、编写React组件并用当前帧控制动画、在Studio中逐帧预览和调整参数，最后运行渲染命令输出MP4。
- 该方式适合React前端团队、需要反复生产同类内容的业务和内容团队、由表格或接口数据驱动内容的数据团队，以及希望把视频生成能力集成进产品的AI或SaaS团队。
- 视频认为，代码并不是要替代剪辑软件，而是在视频需要重复生产、接入数据并进入产品时，提供一条将视频转化为长期可维护软件能力的工程路径。
