# 速览

## 一句话主旨

视频介绍 Pi Agent 采用四个核心原子工具起步、通过扩展补充能力的特点，并分享了并行任务、记忆、联网搜索和代码质量等方向的扩展推荐，帮助用户提升复杂任务处理效率。

## 核心要点

- Pi Agent 初始只提供 `read`、`write`、`edit` 和 `bash` 四个核心原子工具，其他能力需要按需安装官方扩展；视频提到官方扩展数量已超过五千个。
- 第一个推荐的“派stop”扩展可以让主 Agent 拆分复杂任务，并分发给子 Agent 并行执行，适合模块较多、耗时较长的任务。
- `padhammersmemory` 用于补充记忆能力，视频认为长任务中的上下文压缩可能造成信息丢失，安装后可以改善这一问题。
- `padwebaccess` 用于让 Pi Agent 获得联网搜索能力，扩展其获取外部信息的范围。
- 对于使用 Pi Agent 进行项目开发的用户，视频还建议安装代码质量相关扩展，但原文没有清楚说出这些扩展的完整名称。

# 视频原文

agent领域的派最近热度是持续级数级上升，因为小而精，talk消耗低，执行任务快，全球范围已经圈了很多粉，我已经被它粉了两个多月了。但是要用好它是有窍门的，因为小，所以初时安装只有四个核心的原子工具，read、write、edit和bash，其他的工具在需要的时候要自己通过官方提供的扩展来安装。现在官方有五千五百三十九个扩展，但这么多怎么找到自己想要的？这是我用了两个月以来认为安装派后必装的几个扩展。
- 第一个是派stop，agent不装复杂的任务，比如存够五个模块，它只会一个一个的顺序执行，会非常慢。但装上以后主agent就会把任务拆分后分发到子agent并行执行，很适合长任务的朋友们。
- 第二个是padhammersmemory，因为pad的默认记忆就是绘画，如果任务比较长，绘画一多就会被压缩，压缩后上下文可能就会丢失。装上它之后pad就有了记忆。
- 第三个是padwebaccess，这个很简单，其实就是让pad具有联网搜索的能力。
- 第四个是关于代码质量的，如果朋友们会使用pad做项目开发，这个padless和这个一定要装。还有就是这个，这个，这个，这个。
